This AI detects which surgical instrument is what and tells how confident it is on its decision. This is my first AI project that I have succeeded in.

For this you need to download the following:
-pytorch
-torchvision
-numpy
-pillow
-matplotlib

To get the AI to predict put python Inference/predict.py test.jpg in the command prompt and then the prediction and confidence will appear.
The images were taken from https://data.mendeley.com/datasets/cyghvmjrt3/1
